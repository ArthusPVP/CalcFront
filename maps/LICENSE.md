# Map data licence

The map files in this folder (`calc/*.8xv`, `preview/*.png`, and the `pc/*.cfm`
files generated by `tools/mapconv.py`) are derived from the maps of
[OpenFront](https://github.com/openfrontio/OpenFrontIO) (`resources/maps`),
© OpenFront and contributors, licensed under
[Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Changes made for CalcFront: terrain downscaled to at most 256 tiles per side
(and a "Large" version of up to 64,000 tiles for some maps), terrain reduced to
plains / highland / mountain, water bodies labelled, the map edge turned into
water, nation start positions snapped to land, and the result packed into
compressed TI-84 Plus CE AppVars.

These derived map files are shared under the same licence,
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
